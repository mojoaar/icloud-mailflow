Getting Started

1. iCloud Mail Rule

Create a rule on iCloud to route all incoming mail to a "Processing" folder:

  1. Go to icloud.com/mail
  2. Settings gear ⚙ → Rules → Add a Rule
  3. "If a message" → is addressed to → leave address field empty (matches all)
  4. "Then" → Move to Folder → New Folder... → enter Processing
  5. Click Done → Done

2. App-Specific Password

Generate at appleid.apple.com → Sign-In and Security → App-Specific Passwords.

3. Start Mailflow

go run ./cmd/mailflow/ -data=./data

Open http://127.0.0.1:8080/setup → configure admin password + iCloud credentials.

4. Docker

docker compose up -d

Then docker compose restart after first-run setup so IMAP reconnects.

How It Works

Incoming mail → iCloud Rule → "Processing" folder → Mailflow poller → Match rules → Execute actions
  1. iCloud rule moves all mail to Processing folder
  2. Mailflow polls Processing every 300s (configurable)
  3. Each message is checked against rules in priority order (first match wins)
  4. Matched actions execute: move, mark as read, set flags
  5. Unmatched messages go to the catch-all rule
  6. Contacts are auto-collected from processed messages

Rules

Rules match messages by conditions and execute actions. Rules are checked in priority order — lowest number runs first.

Match Logic

  • ANY (OR): Rule matches if any ONE condition is true
  • ALL (AND): Rule matches only if ALL conditions are true
  • Default is ANY — changeable per rule

Drag & Drop Reorder

Grab the ⋮⋮ handle on any rule and drag to reorder. Priority numbers update automatically.

Actions

ActionDescriptionValue
move_to_folderMove message to folderFolder name (autocomplete from IMAP)
mark_as_readSet \Seen flagNone
mark_as_unreadRemove \Seen flagNone
set_flagSet IMAP flagFlag name (e.g. \Flagged, $Junk)

Multiple actions execute in order. Moves are processed first so flags apply to the destination folder.

Contacts

Contacts are collected automatically from processed messages (From/To/Cc headers).

  • Seed Contacts: Bulk import from all synced IMAP folders (200 newest per folder)
  • iCloud Contacts: Import from iCloud address book via CardDAV (Settings → iCloud Contacts)
  • Contact count: Shown on Dashboard and Settings → Server
  • Contacts autocomplete in rule condition value fields

Activity Log

Every rule match and action execution is logged:

  • View at /activity
  • Shows timestamp, subject, sender, rule, action, status
  • Timezone-adjustable in Settings → Regional
  • Clear logs with "Clear Logs" button
  • Auto-cleaned on startup (default 1000 entries, configurable)

API Reference

All API endpoints require authentication (session cookie from login). Base URL: http://127.0.0.1:8080

Health Check

GET / — Redirects to dashboard (200 if authenticated, 303 to login if not).

Manual Poll

POST /poller/tick — Trigger a poll cycle immediately.

curl -X POST http://127.0.0.1:8080/poller/tick -b "mailflow_session=TOKEN"
// JavaScript (fetch)
fetch('/poller/tick', { method: 'POST', credentials: 'same-origin' })
# Python
import requests
r = requests.post('http://127.0.0.1:8080/poller/tick', cookies={'mailflow_session': 'TOKEN'})
# Go
resp, _ := http.Post("http://127.0.0.1:8080/poller/tick", "", nil)
resp.Request.AddCookie(&http.Cookie{Name: "mailflow_session", Value: "TOKEN"})
# PowerShell
Invoke-RestMethod -Uri http://127.0.0.1:8080/poller/tick -Method POST -WebSession $session

Contacts Search

GET /api/contacts?q=<query>

curl http://127.0.0.1:8080/api/contacts?q=alice -b "mailflow_session=TOKEN"

Folders List

GET /api/folders — Syncs folders from IMAP and returns list.

curl http://127.0.0.1:8080/api/folders -b "mailflow_session=TOKEN"

Seed Contacts

POST /contacts/seed — Seed contacts from all synced folders.

curl -X POST http://127.0.0.1:8080/contacts/seed -b "mailflow_session=TOKEN"

Rules CRUD

GET /settings/rules/export — Download all rules as JSON (excludes catch-all).

curl http://127.0.0.1:8080/settings/rules/export -b "mailflow_session=TOKEN" -o rules.json

POST /settings/rules/import — Import rules from JSON file.

curl -X POST http://127.0.0.1:8080/settings/rules/import -b "mailflow_session=TOKEN" -F "rules_file=@rules.json"

iCloud Contacts Import

POST /settings/carddav-import

curl -X POST http://127.0.0.1:8080/settings/carddav-import -b "mailflow_session=TOKEN"

Clear Activity Log

POST /activity/delete

curl -X POST http://127.0.0.1:8080/activity/delete -b "mailflow_session=TOKEN"

Login (get session token)

POST /login — Returns mailflow_session cookie.

curl -X POST http://127.0.0.1:8080/login -d "password=YOUR_ADMIN_PASSWORD" -c cookies.txt
