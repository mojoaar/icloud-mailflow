Introduction

Apple's iCloud Mail rules are basically useless — a single condition, a single action, and no way to chain anything. Combined with a web client they haven't meaningfully updated in years, managing iCloud mail beyond the basics is a dead end.

Mailflow fixes that. It connects to iCloud via IMAP, runs your incoming mail through a real rules engine (AND/OR logic, 10 condition operators, multiple actions), and handles it all automatically.

Getting Started

1. iCloud Mail Rule

Create a rule on iCloud to route all incoming mail to the Processing folder:

  1. Go to icloud.com/mail
  2. Settings gear → Rules → Add a Rule
  3. If a message → is addressed to → leave address empty
  4. Then → Move to Folder → New Folder… → enter Processing
  5. Click Done twice

2. App-Specific Password

Generate at appleid.apple.com → Sign-In & Security → App-Specific Passwords.

3. Start the App

go run ./cmd/mailflow/ -data=./data

Open http://{{.Host}}/setup → configure admin password + iCloud email + app password.

4. Docker

docker compose up -d
docker compose restart  # after setup → IMAP reconnects

How It Works

Incoming mail → iCloud Rule → "Processing" folder → Mailflow poller → Match rules → Execute actions
  1. iCloud rule moves all incoming mail to the Processing folder
  2. Mailflow polls Processing every 300s (configurable, default 50 messages/poll)
  3. Each message is checked against your rules in priority order (lowest first)
  4. First matching rule's actions execute — if none match, the catch-all handles it
  5. Contacts are auto-collected from message headers (From, To, Cc)

Rules & Conditions

Rules are checked in priority order — lowest number runs first. Reorder via drag & drop.

Condition Fields

FieldMatchesExample

Operators

equals · not_equals · contains · not_contains · starts_with · ends_with · matches_regex · exists · not_exists

Match Logic

  • ANY (OR): Rule fires if any ONE condition is true — default for new rules
  • ALL (AND): Rule fires only if every condition matches

Actions

ActionWhat it doesValue
move_to_folderMove message to folderFolder name
mark_as_readSet \Seen on messageNone
mark_as_unreadRemove \SeenNone
set_flagSet IMAP flage.g. \Flagged, $Junk

Multiple actions execute in declaration order. Moves run first so flags apply in the destination folder.

Contacts

Collected automatically from processed messages. Seed from all folders via Dashboard.

  • Seed Contacts — Bulk import across all IMAP folders (newest 200 each)
  • iCloud Contacts — Import address book via CardDAV (Settings)
  • Autocomplete — Contacts suggest in rule condition value inputs
  • Count — Shown on Dashboard and Settings → Server

Activity Log

Every rule match and action execution is logged. View at /activity.

  • Shows timestamp, subject, sender, rule, action, and status
  • Timezone-adjustable in Settings → Regional
  • Clear logs with "Clear Logs" button
  • Auto-cleaned on startup (default 1000 entries, configurable in Settings)

Stats Dashboard

Visit /stats for rule hit counts, top senders, actions breakdown, daily/weekly volume, messages by folder, and more. Stats are stored independently from the activity log — clearing logs preserves all statistics.

MCP Server

Mailflow exposes a Model Context Protocol (MCP) server so AI agents (Claude Code, OpenCode, Codex) can manage rules, check stats, and trigger polls remotely. Enable it in Settings → MCP Access — you get an API key and ready-to-use config snippets for all platforms.

The server runs over HTTPS on /mcp. All 12 tools require a Bearer token in the Authorization header.

API Reference

Base URL: http://{{.Host}}. All endpoints require session cookie from POST /login.

Authentication

POST POST /login

Authenticate. Returns mailflow_session cookie. Rate limited: 5/min/IP.

curl -X POST http://{{.Host}}/login -d "password=YOUR_PASSWORD" -c cookies.txt

GET GET /logout

Clear session cookie and redirect to login.

curl http://{{.Host}}/logout -b cookies.txt

Polling

POST POST /poller/tick

Trigger a manual poll cycle immediately.

curl -X POST http://{{.Host}}/poller/tick -b cookies.txt

POST POST /settings/poll/toggle

Enable or disable automatic polling.

curl -X POST http://{{.Host}}/settings/poll/toggle -b cookies.txt

Rules

POST POST /rules

Create a new rule. Conditions and actions parsed from form data.

curl -X POST http://{{.Host}}/rules -b cookies.txt \
  -d "name=My+Rule&enabled=on&cond_field=from&cond_op=contains&cond_value=@work.com&cond_operator=OR&action_type=move_to_folder&action_value=Work"

PUT PUT /rules/{id}

Update an existing rule. Use _method=PUT in form data.

curl -X POST http://{{.Host}}/rules/1 -b cookies.txt \
  -d "_method=PUT&name=Updated+Rule&enabled=on"

DEL DELETE /rules/{id}

Delete a rule by ID. Use _method=DELETE in form data.

curl -X POST http://{{.Host}}/rules/1 -b cookies.txt -d "_method=DELETE"

POST POST /rules/reorder

Reorder rules by priority. Submit rule_ids in the desired order.

curl -X POST http://{{.Host}}/rules/reorder -b cookies.txt \
  -d "rule_ids=3&rule_ids=1&rule_ids=2"

GET GET /settings/rules/export

Download all rules as JSON (excludes catch-all).

curl http://{{.Host}}/settings/rules/export -b cookies.txt -o rules.json

POST POST /settings/rules/import

Import rules from a JSON file.

curl -X POST http://{{.Host}}/settings/rules/import -b cookies.txt \
  -F "rules_file=@rules.json"

Settings

POST POST /settings/imap

Save IMAP connection settings.

curl -X POST http://{{.Host}}/settings/imap -b cookies.txt \
  -d "imap_email=user@icloud.com&imap_password=app-password"

POST POST /settings/imap/test

Test IMAP credentials without saving. Falls back to stored credentials if fields are empty.

curl -X POST http://{{.Host}}/settings/imap/test -b cookies.txt

POST POST /settings/password

Change admin password. Leave blank to keep current.

curl -X POST http://{{.Host}}/settings/password -b cookies.txt \
  -d "password=new-password"

POST POST /settings/poll

Save polling settings (source folder, interval, batch size, log retention).

curl -X POST http://{{.Host}}/settings/poll -b cookies.txt \
  -d "source_folder=Processing&poll_interval=300&poll_batch=50&log_keep=1000"

POST POST /settings/timezone

Set display timezone.

curl -X POST http://{{.Host}}/settings/timezone -b cookies.txt \
  -d "timezone=Europe/Copenhagen"

POST POST /settings/font

Set UI font (default or mono).

curl -X POST http://{{.Host}}/settings/font -b cookies.txt -d "font=mono"

Backup

POST POST /settings/backup/save

Save backup settings (enabled, frequency, recipient).

curl -X POST http://{{.Host}}/settings/backup/save -b cookies.txt \
  -d "backup_enabled=true&backup_frequency=weekly&backup_recipient=user@icloud.com"

POST POST /settings/backup/now

Trigger an immediate rules backup to the configured recipient.

curl -X POST http://{{.Host}}/settings/backup/now -b cookies.txt

Contacts & Folders

GET GET /api/contacts?q=<query>

Search contacts by email or name.

curl 'http://{{.Host}}/api/contacts?q=alice' -b cookies.txt

GET GET /api/folders

Sync folders from IMAP and return the list.

curl http://{{.Host}}/api/folders -b cookies.txt

POST POST /contacts/seed

Seed contacts from all synced IMAP folders.

curl -X POST http://{{.Host}}/contacts/seed -b cookies.txt

POST POST /settings/carddav-import

Import contacts from iCloud address book (CardDAV).

curl -X POST http://{{.Host}}/settings/carddav-import -b cookies.txt

Activity

POST POST /activity/delete

Clear all activity logs.

curl -X POST http://{{.Host}}/activity/delete -b cookies.txt

MCP Server

POST POST /mcp

MCP JSON-RPC endpoint for AI agent access. Requires Bearer token authentication (enabled via Settings).

curl -X POST http://{{.Host}}/mcp \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

  }
